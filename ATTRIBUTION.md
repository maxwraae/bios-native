# Attribution

Every asset Bios includes, with its author, source and licence. `cargo xtask assets` fails if an
asset file is missing from this table.

Bios contains no SnapGene or other third-party product's icons, images, fonts or
artwork. The sequence files under `crates/*/tests/fixtures/` are the Bios project's own test
constructs and recorded reference answers.

| Asset | Author | Source | Licence | Used for |
|---|---|---|---|---|
| `crates/bios-ui/assets/fonts/InstrumentSans.ttf` | The Instrument Sans Project Authors | https://github.com/Instrument/instrument-sans (via google/fonts `ofl/instrumentsans`) | OFL-1.1, `crates/bios-ui/assets/fonts/OFL-InstrumentSans.txt` | Interface text |
| `crates/bios-ui/assets/fonts/InstrumentSerif-Regular.ttf` | The Instrument Serif Project Authors | https://github.com/Instrument/instrument-serif (via google/fonts `ofl/instrumentserif`) | OFL-1.1, `crates/bios-ui/assets/fonts/OFL-InstrumentSerif.txt` | Titles |
| `crates/bios-ui/src/lucide.rs` (icon shapes as data) | Lucide Icons and Contributors | https://lucide.dev, lucide-react 1.24.0, the icons the Bios web app imports; generated by `gen-icons.mjs` | ISC, `crates/bios-ui/assets/LICENSE-Lucide.txt` | Toolbar, sidebar and menu icons |

The sequence font is the system's SF Mono, loaded at run time on macOS and not shipped.
